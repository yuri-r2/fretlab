# Fretlab

A guitar practice app in a single HTML file. Open `index.html` in any modern browser, or turn on GitHub Pages for this repo to use it from your phone.

## What's inside

- **Today**: guided routines (15, 20, 30 and 45 minutes) that open each tool and time every block, plus a daily goal, streak and 7-day chart.
- **Metronome**: click, wood, beep or drum beats (rock, half-time, four on the floor, funk, shuffle), swing, tap tempo, time signatures, subdivisions, per-beat accents, a speed trainer, a gap trainer and a tempo log. The space bar starts and stops it from any tab.
- **Fretboard trainer**: find the note, name the note, intervals, and find them all. It asks more often about notes you miss or answer slowly. A progress map shows what you've learned.
- **Ear trainer**: scale degrees in a key (cadence, then a note, then it resolves home), intervals, and chord types, with levels that unlock at 90% over 20 questions.
- **One-minute changes**: a 60-second chord change counter with history for each chord pair.
- **Scales**: 10 scales in any key across the five CAGED positions, with chord tones, playback and a root drone.
- **Riff Dice**: roll notes and rhythms, lock what you like, loop over drums, and save riffs.
- **Tuner and drone**: reference tones for seven tunings, and a drone for scale practice.

Progress is saved in your browser's local storage.

## Practice methods it's based on

- Interleaved practice: [Carter and Grahn, 2016, Frontiers in Psychology](https://www.frontiersin.org/articles/10.3389/fpsyg.2016.01251/full)
- One-minute changes: [JustinGuitar](https://justinguitar.com/guitar-lessons/one-minute-changes-exercise-b1-110)
- Functional ear training: [Functional Ear Trainer](https://apps.apple.com/app/id1088761926)

## Run it with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. Your app will be at `https://<your-username>.github.io/fretlab/`.
